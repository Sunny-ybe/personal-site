1. **Commits are mine only.** No AI co-author lines, no AI as author, no "Generated with" footers in commits or PRs.
2. **Commit and push only when I say so.** Check for new commits on GitHub before pushing; never force-push without asking me.

4. **List changed files.** End every reply that changes anything with the exact paths touched, or say nothing changed.
5. **Flag personal details before publishing.** If something about to be published contains a personal detail (ID number, phone, address, birth date, etc.), stop, name it, recommend redacting it, then do what I decide.
6. **Keep claims honest.** Don't invent features, roles, numbers, or awards on the site; label concepts and prototypes as such.
